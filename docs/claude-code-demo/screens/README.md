## Differences from the design

**Changed on purpose in this branch**

1. NRICs are masked everywhere (`F****488P`) with a "Show" link on Ops details (audited, D-41); the design shows full NRICs.
2. Customer link check (05a): no NRIC row and no "Only the person with NRIC S****345Z…" sentence (no personal data on
   the customer pages). The design's "Other state" panel is a separate screen (05b).
3. Simulated Singpass login (06b): a list of the 9 test personas replaces the "Open Singpass app" button (the presenter
   has to pick a persona). The gateway landing (06a) and review (08a) pages follow `singpass-reference/` (no design).
4. Ops details (11*): additions — status chip next to the reference, "Correct NRIC / email" button, link history with
   "no longer valid" labels, "Activity" log (the design shows a single red note), extra MyInfo rows (date of birth,
   employer, CPF, housing). The "Cannot issue AA yet" box lists only the Singpass condition of each person; the design's
   "Mandatory documents accepted" and "FI Review completed" lines are not shown (D-10, D-11).
5. Ops list (10): "Expired links (n)" and "Demo Control" buttons instead of "+ New Application"; a second guarantor is
   listed under the first one.
6. Quick Apply (01): "Fill sample (test personas)" button and an "Add a second guarantor" toggle inside the guarantor box.
7. "Demo time: +N h" bar above the header on presenter screens while the clock is moved (12, 13); not in the design.
8. Expired links list (12) and Demo Control (13) have no design; they reuse the same components.

**Earlier differences, still open**

9. Dealer sidebar: "My Applications / Quick Apply / Account" instead of "Home / Application / Account"; a "Switch role"
   button in the header (D-08).
10. Demo shortcut buttons of the design are not built: "Demo: see what the hirer gets" (Received), "Demo: see the Ops
    view" (Dealer Status), "Demo: see the dealer's view" (Done). Received has "Show QR of the link" and "View Application
    Status" instead.
11. Customer email (04): the screenshot is the email body only; the design draws it inside a mail-client frame.
12. Ops list: no search box or filters (out of scope, brief §12). Ops details: no bottom bar (Cancel, FI Review
    Completed, Decline, Save — out of scope); vehicle make / model show "— (via LTA, out of scope)"; car plate "—" for
    new applications.
13. Consent list (07) shows 8 data items (the design shows 6).
