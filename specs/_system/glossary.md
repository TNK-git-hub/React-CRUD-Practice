# Glossary — React-CRUD-Practice (product management)

Brownfield: the app already runs. Terms come from `docs/requirements/price-range.md` and, for behavior that already
exists, from the code named in the Source column (the requirement document says the current code is the source of
truth for existing behavior).

| Term | Definition | In code | Do not use | Source |

| Price range | A minimum price and/or a maximum price (USD) a visitor enters to narrow the product list; both ends included (see `capabilities/products/rules.md`) | `minPrice`, `maxPrice` | price filter range, budget | docs/requirements/price-range.md#Requirement |
| Minimum price | Lower end of the Price range; empty = no lower limit | `minPrice` | — | docs/requirements/price-range.md#Requirement |

| Search | Keyword `q`, partial and case-insensitive match on `title` or `description` | `q` | — | backend/src/products/products.service.ts |
| Sort | By `title`, `price`, `rating` or `stock`, direction `asc` / `desc`; ties are ordered by ascending `id`.
